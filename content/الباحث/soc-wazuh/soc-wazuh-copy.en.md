## Instagram (≤150 words)
What does a license-free security operations center look like?
I built one as a graduation project from open-source tools: Wazuh as SIEM, Suricata for intrusion detection, YARA and VirusTotal for file scanning, and auditd for command auditing—in a virtual lab with Windows 10 and Kali Linux.
Every use case is documented step by step: the event, the rule it fires, and at what level. Example: one Shellshock request to Apache → rule 31168 → a level-15 alert mapped to MITRE T1068/T1190.
