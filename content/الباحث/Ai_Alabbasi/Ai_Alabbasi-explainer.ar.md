# كيف يعمل Ai_Alabbasi — نواة وكيل تملكها

الوكلاء البرمجية الجاهزة تُستأجر: عقلها نموذج واحد لا تختاره، ومعرفتها تبقى عند المزوّد، وكودك يمرّ عبر منصة مغلقة. Ai_Alabbasi يبدأ من السؤال المعاكس: ماذا لو كانت نواة الوكيل ملفات Python قليلة تقرأها في جلسة، تشغّلها على خادمك، وتبدّل عقلها متى شئت؟ المستودع 31 ملف Python و3,318 سطرًا، بتبعية إلزامية واحدة (PyYAML)، وترخيص MIT.

**العقل: سطر واحد.** ملف `brain/brain_config.yaml` يحمل 8 إعدادات جاهزة ومفتاح `active_brain` واحد؛ تغييره يبدّل النموذج لكل الحلقة، بما فيها نموذج محلي عبر أي خادم متوافق مع واجهة OpenAI. المفاتيح في `config/.env` خارج git (فُحص التاريخ كاملًا: لا مفتاح مرفوع). وإن غاب المفتاح لا ينهار شيء — يُبثّ حدث `error` صريح في الطرفية والواجهة، كما رأينا عند التشغيل بلا مفتاح.

**الحلقة: خطّة، تنفيذ، انعكاس.** قبل التنفيذ يولّد المخطِّط خطة مرقّمة، وتحتفظ قائمة المهام بـ«تلاوة» الهدف كي لا يضيع في الخطوات. آلة حالات بست حالات (idle → running → interrupted/resuming → done/failed) تحرس الانتقالات، ومعالج مقاطعة آمن الخيوط يوقف التنفيذ في منتصفه. الحدّ 25 خطوة لكل مهمة، وكل خطوة تُسجَّل في تيار أحداث بستة أنواع موحّدة يُصيَّر سياقًا للعقل.

**الأدوات: تسعة، محصورة.** قراءة وكتابة وإلحاق واستبدال جراحي للملفات، سرد وإنشاء المجلدات، بحث ويب، تنفيذ أوامر، و`run_python` الذي ينفّذ الكود في عملية معزولة داخل `projects/` (نمط CodeAct). كل مسار يمرّ عبر `_safe_path` فلا يخرج الوكيل من مجلده. صندوق الرمل قابل للتبديل بين local وDaytona وE2B بسقوط آمن إلى المحلي.

**المعرفة: يبحث قبل أن يبني.** قاعدة SQLite بـ FTS5 للنص، ومتجهات دلالية (sentence-transformers إن وُجدت، وإلا بديل hashing مضمّن)، تُدمَج نتائجهما بـ Reciprocal Rank Fusion (k=60). أمر `ingest.py` غذّى 87 مقطعًا لثلاث تقنيات في تشغيلنا. قبل كل مهمة تُحقن المعرفة المناسبة في العقل؛ وبعد كل نجاح تُحفظ الخبرة مهارة. فهرس المهارات يكشفها تدريجيًا بثلاث طبقات ويطابق العربية مطابقة ضبابية، مع 5 مهارات بذرية.

**الواجهتان.** CLI بستة أوامر، وواجهة ويب RTL ببثّ حي و12 مسار API تعرض العقل الحالي ولوحة المهارات ومسار التنفيذ. 74 اختبارًا تغطي الحلقة والمعرفة والأدوات — أُعيد تشغيلها محليًا: 74 ناجحًا في 2.18 ثانية.

**الجيل الثاني.** منصور بُني لاحقًا من الصفر «مستلهمًا أنماطه» (كما يوثّق ملف قراراته)، بسبعة وكلاء و13,908 سطر. Ai_Alabbasi يبقى النواة القابلة للقراءة التي تُظهر كيف يُبنى وكيل تملكه.
