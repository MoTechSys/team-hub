# نصوص النشر — Motech CLI (عربي)

## LinkedIn (≤120 كلمة)
ربط جهاز عميل واحد بمنصة وصول آمن كان يحتاج مثبّتاً رسومياً لكل نظام، ومفتاح SSH يُنسخ باليد، وخدمة تُضبط بعد ذلك.

Motech CLI يختصرها في أمر واحد: `motech setup` يبادل رمز تفعيل لمرة واحدة، ينضم إلى شبكة NetBird بـ SSH المدمج، يثبّت المفتاح العام الذي يملكه الخادم، ويسجّل خدمة خلفية تبعث heartbeat وتنفّذ تدوير المفاتيح من الخادم — على Windows وLinux وmacOS.

القرار الأهم: لا مفتاح خاص على جهاز العميل أبداً. الرمز لا يُمرَّر كوسيط، TLS صارم، SHA256 قبل التثبيت، وإصدار موقَّع cosign.
