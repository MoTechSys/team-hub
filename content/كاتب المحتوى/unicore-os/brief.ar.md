# UniCore-OS — نظام إدارة جامعي عربي بصلاحيات دقيقة وميزات ذكاء اصطناعي اختيارية

**الشريحة:** طلاب (مشاريع التخرج / أنظمة جامعية)
**المشكلة:** إدارة الجامعة مجزّأة بين مستخدمين وأدوار وهيكل أكاديمي وكويزات ودرجات، وأغلب الأنظمة ليست عربية ولا تمنح صلاحيات دقيقة.
**الحل:** نظام واحد بـ Next.js وPrisma: 52 صلاحية وأدوار مخصصة، هيكل كليات → أقسام → تخصصات → مقررات → شُعب، محرك كويزات (اختيار من متعدد، صح/خطأ، إجابة قصيرة، مؤقت) مع توليد أسئلة وتصحيح بالذكاء الاصطناعي، ملفات وإشعارات وتقارير وكشف درجات، وسلة مهملات لا تُحذف منها البيانات نهائياً. واجهة عربية RTL بالكامل.
**النتيجة بالأرقام:** 52 صلاحية، 22 جدولاً، 26 صفحة، 15 وحدة، صفر أخطاء TypeScript، وزحف 102 صفحة عبر 3 أدوار بلا مشاكل. الإصدار 2.0.0-rc.4.
**لمن يفيد:** طلاب مشاريع التخرج وأقسام الحاسب التي تريد نظاماً جامعياً عربياً مفتوح المصدر قابلاً للتوسعة.
**للتواصل:** المستودع مفتوح — اسألني.
