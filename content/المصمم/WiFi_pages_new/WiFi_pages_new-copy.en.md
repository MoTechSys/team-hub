# Glassmorphism hotspot portal — publishing copy

## LinkedIn (≤120 words)
I redesigned a MikroTik hotspot login page without touching a single line of JavaScript.

The page isn't plain HTML: it's a template the router fills with 27 variables, a form with fixed field names, and MD5 in the browser. Change any of that and every user's login stops.

So all of it stayed, and only the CSS layer changed: animated gradient, frosted-glass cards, 9 animations — in 19.9 KB with zero external libraries. 8 templates: login, status, success, logout, error, block, advert, redirect.

Along the way I found a bug: a neon rule on the first h1 was hiding the status page's button labels. Documented.

Repo: github.com/moain2028/WiFi_pages_new
