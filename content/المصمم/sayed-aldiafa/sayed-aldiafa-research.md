# سيد الضيافة — بحث وتحليل السوق

## English summary
Sayed Al-Diafa is a 15-page, zero-dependency, RTL static site for a Riyadh event-rental contractor. The category (event rentals: stages, tents, chairs, AV, coffee servers) is served in Riyadh mostly by WordPress/Elementor sites or agency-templated Bootstrap/jQuery sites, all converting through WhatsApp. Our differentiators, all measured from code: no framework/no build (competitors ship 68–83 script tags vs. 2–3 here), 27 JSON-LD blocks (competitors 0–1), 56/56 alt texts, and a serverless booking form that becomes a pre-filled WhatsApp message. Gaps: no live URL, AI-generated imagery only, stale README, no prices, no tests, 480px-max layout on desktop, Google Fonts dependency.

**أين يتفوّق مشروعنا (من tech.md فقط):**
- **بلا إطار وبلا build وصفر اعتمادية** مقابل WordPress بإضافات (Elementor/Slider Revolution) أو Bootstrap/jQuery: 2–3 وسوم script في صفحاتنا مقابل 68–83 عندهم.
