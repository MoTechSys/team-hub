# Sayed Al-Diafa — publishing copy

## LinkedIn (≤120 words)
I built an events website with no framework. In 2026.

Sayed Al-Diafa: 15 pages of plain HTML/CSS/JS, fully RTL Arabic, mobile-first. Zero dependencies, zero build — the file you edit is the file that gets served, and it uploads as-is to any host.

The part I like most: the booking form needs no server. Eight fields become a pre-filled WhatsApp message via JavaScript and open ready to send.

Under the surface: 27 JSON-LD blocks, Open Graph and canonical on every page, 56/56 images with alt text, no zoom lock.

For a 15-page site this is the right call. If the content grows, a Next.js version exists.
