# A premium mobile UI with no framework — contrast measured, not eyeballed

**Segment:** Small business
**Problem:** A small hospitality business wants a premium mobile UI that stays readable in a dim majlis — no framework, no build, nothing beyond a static host.
**Solution:** One hand-written HTML/CSS/JS page, full RTL, a 21-variable palette with a five-stop gold gradient, drawer, tab bar and a floating WhatsApp button that hides while scrolling — every text's contrast checked with getComputedStyle.
**Results in numbers:** 31.2 KB of code (9.7 KB gzipped), 20 first-load requests, 15/15 texts above 4.5:1, zero FAB/tab-bar overlap, LCP 232 ms locally.
**Who it helps:** Small businesses that want a premium, lightweight mobile UI and own its three files.
