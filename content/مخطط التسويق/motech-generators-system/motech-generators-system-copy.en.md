# Publishing copy — MoTech Generators System

## LinkedIn (≈130 words)
A generator station run on a single Excel workbook: readings copied by hand, a fuel balance held together by formulas, and nobody knows who changed what.

MoTech Generators System takes the same formulas and puts them inside the database: pick a generator, the previous reading loads, and 5 values compute instantly (operating hours, transformer and screen sales, output per litre) as generated columns in PostgreSQL — not in the UI.

Around it: a running diesel balance, a 13-field maintenance log, 8 CSV/printable reports, 4 analytics charts, and 39 permissions across 11 modules that the admin composes into roles with any name, with a full audit log.

Fully Arabic RTL, multi-company and multi-branch, plain JavaScript with no framework.

Still running your generators on Excel? DM me.
