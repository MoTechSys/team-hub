# Hafawa — a Riyadh events website measured in milliseconds

## Executive summary (5 points)
1. An Arabic website for a hospitality and event-catering company in Riyadh, covering 24 districts with a dedicated page per district for local search — 32 pages in total.
2. The architectural decision: remove the framework rather than add one — plain HTML, CSS and JS, no framework and no CMS, generated by a Python script from a single data file (`build/data.py`).
3. Numbers measured, not estimated: FCP 324 ms, CLS 0.003, a 201 KB homepage in 13 requests, images cut from 24.4 MB to 3.37 MB (86%), 15/15 texts passing WCAG AA, zero broken links.
4. Auditing is part of the build: `audit.py` measures contrast, links, overlap and horizontal overflow before every release.
5. Status: complete and automatically audited; not yet published on a public domain at inventory time, runs locally — live link to be confirmed.

## The problem
Event-catering sites are usually hand-built page by page on a heavy template: full-size images, a framework or CMS that loads more than needed, and any update (a price, a new district, a service) needs a developer. The result is a slow site on a phone with an average connection — exactly the device an events customer actually uses — and weak coverage in Riyadh's district-level local search.

## How it works
The site is fully static. One data file (`build/data.py`) holds services, rentals, the 24 districts, packages, FAQs and navigation. `site.py` reads it and generates 32 HTML pages (8 main + 24 districts) plus `sitemap.xml` and `robots.txt` in one command; change one line and everything rebuilds.

The image pipeline `images.py` takes every source image and emits AVIF, then WebP, then JPEG at multiple sizes inside a `<picture>` element with an inline low-resolution placeholder — 86 derived image files, with AVIF 39% smaller than WebP. Before release, `audit.py` checks text contrast, broken links, element overlap and horizontal overflow.

For local search: LocalBusiness JSON-LD structured data listing all 24 districts in `areaServed` with an offer catalog, Arabic Open Graph, and `geo.region=SA-01`. For accessibility: `prefers-reduced-motion` respected, a skip link, and `aria-current` / `aria-expanded` attributes.

## Who it is for
Event and hospitality businesses — and any multi-area local business — that want a site that opens instantly on mobile and is updated from one place without calling a developer each time.

## What sets it apart
Numbers, not promises: a 32-page site that paints first content in 324 ms — more than five times faster than Google's "good" threshold for FCP (1.8 s). No application server, no database, no framework security patches — the whole deployment is 4.17 MB in 127 files.

## Current status and what remains
Complete and automatically audited (latest commit: "clean automated audit · WCAG AA 15/15"). Not published on a public domain at inventory time (2026-09-11); runs locally. The original repository is private; the public copy is on moain2028.
