# Kitabi — post copy (EN)

## LinkedIn (≤120 words)
A course project that needs a full store—browse, cart, order, account—without paying for a cloud backend.

Kitabi is a Flutter app that does all of it with no server: 24 books in 6 categories, search and filters, a cart with coupons, favorites, ratings, and order tracking. All data lives in a local SQLite database seeded on first launch, and password reset runs through a three-step OTP flow.

Version 1.1.0: 17 screens, 31 passing tests, a ready APK, a build guide, and architecture docs.

For mobile-development students who want a complete example that runs and reads well.

The repository is open — ask me.
