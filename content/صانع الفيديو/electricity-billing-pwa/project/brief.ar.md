# نظام فواتير الكهرباء V2 — الفاتورة الرسمية من جوال الموظف، بلا خادم ولا إنترنت

**الشريحة:** شركات (محطات الكهرباء والمولدات الأهلية)
**المشكلة:** النسخة الأولى كانت تحتاج خادماً وقاعدة بيانات ومصادقة، والمحطة الصغيرة تريد تطبيقاً يُثبَّت على جوال الموظف ويُصدر فاتورة رسمية حتى بلا شبكة.
**الحل:** أعدت بناء النظام تطبيقَ ويب تقدّمياً محلياً بالكامل بـ Next.js وTypeScript وTailwind: قاعدة البيانات في الجهاز نفسه (IndexedDB عبر Dexie)، صفر مسارات API، فاتورة A4 تُطبع نصاً وتُشارك PDF عربياً حقيقياً داخل المتصفح، حساب فوري للاستهلاك والمستحق مع تفقيط عربي، أرشيف قابل للتصفية، ونسخة احتياطية JSON تُصدَّر وتُستورد بنقرة.
**النتيجة بالأرقام:** من 10 مسارات API وخمسة جداول Prisma إلى 0 مسارات و3 جداول محلية؛ commit التحوّل حذف 3,169 سطراً وأضاف 682؛ 9 صفحات، 31 commit، وبناء بصفر أخطاء TypeScript. لا اختبارات آلية بعد.
**لمن يفيد:** محطات الكهرباء والمولدات الصغيرة والمحصّلون الذين يعملون من الهاتف.
**للتواصل:** محطتك تكتب الفواتير باليد؟ راسلني وأرسل لك النسخة التجريبية على جوالك.
