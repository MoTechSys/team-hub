# Publishing copy — Keif Al-Diafa (Operations App)

## LinkedIn (≤120 words)
A Saudi coffee-hospitality business ran its events on a paper ledger: hosts double-booked in the same slot, cup shortages surfacing on event day, host payouts lost between pages.

I built them an offline mobile app (React Native + SQLite) covering the whole cycle: client → event → hosts → quote → invoice → prep and return → payouts.

The core idea: hiding a button is not protection. The database itself rejects overlapping bookings and over-issued stock — 3 trigger-enforced constraints, 18 tables, 14 screens, and a backup to Google Drive.
